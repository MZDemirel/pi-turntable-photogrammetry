# veri/

Fotoğraflar, COLMAP çalışma klasörleri ve nokta bulutları buraya konur. Bu klasörün içeriği
(bu dosya hariç) git'e gönderilmez.

Önerilen düzen:

```
veri/
  desen/                      01_charuco_desen.py çıktısı (desen.json, desen.pdf)
  on_calisma_1/
    goruntuler/               çekilen fotoğraflar
    colmap/                   02_colmap_olcekle.py çalışma klasörü
    netlik/                   03_netlik_testi.py çıktıları
```
